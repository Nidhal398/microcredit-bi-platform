# Power BI

The Angular dashboard page embeds a Power BI Service report through an iframe URL configured in source. This confirms the web integration path, not the report contents or accessibility to every viewer.

No PBIX, PBIP, PBIT, report export, or approved screenshot is present in the project directory. Therefore this repository cannot document individual report pages, KPI definitions, refresh settings, or conditional-formatting rules based on report inspection.

Before sharing screenshots, check that they contain no beneficiary details, internal account identifiers, or confidential business information. A public repository does not grant viewers access to a protected Power BI report.
