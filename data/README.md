# Local data files (not published)

This directory is intentionally empty in the public repository except for this note. The local project contains a contract-level ML extract with 13,632 records and identifying/financial attributes, plus derived CSV files. Those files are company data and must not be committed.

The local API currently expects:

- contrats_ml.pkl — required by api/train_emplois.py and the training notebook; private
- emplois_cohortes.csv — aggregate used by the employment endpoint; generated by training; company-derived
- profil_segments.csv — segment profiles used by the segmentation endpoint; company-derived
- serie_mensuelle.csv and prevision_3_mois.csv — forecast history and stored forecast; company-derived
- segments_contrats.csv — contract-to-segment export; contains contract identifiers; private

Use only data whose owner has authorized local processing. For a public demo, create a synthetic dataset and retrain/re-export artifacts separately. Do not copy the original Excel, SQL dump, or DWH records into this repository.
